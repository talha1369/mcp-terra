Motivation

On your laptop, AI runs your code. On Terra, it can't.

💻 Laptop

Claude Code writes and runs your code — reads the error, fixes it, runs again. A tight loop.

☁️ Terra today

An assistant can only copy a notebook to the bucket. It can't size a VM, start it, run, or fix a failure.

So you fall back to manual clicking — pick a machine, wait, open Jupyter, run, read the traceback, repeat. For 1,000+ non‑expert Terra users, that's the wall.

Main goal

A credentialed, safety‑gated bridge for AI on Terra.

Claude drives the whole loop — the experience you already get locally:

  • Provision the right‑sized VM (CPU / GPU / RAM) for the notebook
  • Run it, auto‑fix the bugs that surface, run again
  • Explain — emails a verified report + a NotebookLM‑style audio walkthrough of the results and the bugs it fixed

Who benefits: every Terra user — no MCP, cloud, or DevOps background. You type a sentence; the agent does the cloud.
